Para este ejercicio hay que asumir que el juego se juega infinitamente


Globales:   
la bolsa no debe contener mas bolitas que la cantidad de generadores que se encuentran jugando.

```
Semaphore generadores = new Semaphore(0,true);
Semaphore bolitas = new Semaphore(0,true);
Semaphore mutexConsumir = new Semaphore(0,true);
Semaphore mutexPuntosG = new Semaphore(0,true);
Semaphore mutexPuntosC = new Semaphore(0,true);


int puntosG = 0;
int puntosC = 0;
```


Generadores:  
Crean bolitas una a la vez y las colocan en la bolsa. Suman un punto por cada bolita en la bolsa.

```
// Nuevo generador ingresa
generadores.release();

while(true){
  // Se fija que no haya mas generadores que bolitas
  generadores.acquire(); 
  
  bolitas.release(); 

  mutexPtosG.acquire();
  puntosG++;
  mutexPtosG.release();
}
```


Consumidores:   
Toman pares de bolitas y suman un punto por cada par (pero no pueden tomar mas de un par a la vez)
```
while(true){
  // Asumo finitos consumidores para esto
  bolitas.acquire();
  generadores.release();
  bolitas.acquire();
  generadores.release();

  mutexPtosC.acquire();
  puntosC++;
  mutexPtosC.release();
}
```
