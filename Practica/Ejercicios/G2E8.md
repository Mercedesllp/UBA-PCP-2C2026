Para este ejercicio hay que asumir que el juego se juega infinitamente

Globales:   
la bolsa no debe contener mas bolitas que la cantidad de generadores que se encuentran jugando.

```
int puntosG = 0;
int puntosC = 0;

Semaphore mutexGen = new Semaphore(1, true);
Semaphore mutexPuntosG = new Semaphore(1, true);
Semaphore mutexPuntosC = new Semaphore(1, true);
Semaphore mutexConsumir = new Semaphore(1, true); 
Semaphore capacidadBolsa = new Semaphore(0, true); 
Semaphore bolitasDisponibles = new Semaphore(0, true); 
```

Generadores:  
Crean bolitas una a la vez y las colocan en la bolsa. Suman un punto por cada bolita en la bolsa.

```
capacidadBolsa.release(); 

while(true) {
  capacidadBolsa.acquire();
  bolitasDisponibles.release(); 

  mutexPuntosG.acquire();
  puntosG++;
  mutexPuntosG.release();
}
```


Consumidores:   
Toman pares de bolitas y suman un punto por cada par (pero no pueden tomar mas de un par a la vez)
```
while(true) {
  mutexConsumir.acquire();
  bolitasDisponibles.acquire(); 
  bolitasDisponibles.acquire(); 
  mutexConsumir.release();

  capacidadBolsa.release();
  capacidadBolsa.release();

  mutexPuntosC.acquire();
  puntosC++;
  mutexPuntosC.release();
}
```
