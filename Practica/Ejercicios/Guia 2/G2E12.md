# Ejercicio 12 - Guia 2

Se desea modelar el control de tránsito de un puente que conecta dos ciudades.
Dado que el puente es muy estrecho se debe evitar que dos autos circulen al mismo tiempo en dirección opuesta, dado que quedarían atascados. Resuelva los siguientes problemas usando semáforos, modelando cada coche como un thread independiente que desea atravesar el puente en alguna de las dos direcciones posibles (tenga en cuenta que atravesar el puente no es una acción atómica, y por lo tanto, requiere de cierto tiempo),

a) De una solución que permita que varios coches que se desplazan en la misma dirección puedan circular simultáneamente.

b) Modifique la solución anterior para que como máximo 3 coches puedan circular por el puente al mismo tiempo.

c) Indique si la solución propuesta en el punto b es libre de inanición. Justifique su respuesta.

## Punto a

Globales:
```
int autosEnVia = 0;
int dirActual = 0;
int esperando = 0;

Semaphore mutex = new Semaphore(1,true);
Semaphore[] barraDePaso = {new Semaphore(0,true), new Semaphore(0,true)};
```

Auto:
```
Thread auto(int dir):

  mutex.acquire();
  if(autosEnVia == 0 && dir != dirActual){
    dirActual = dir;
  }

  if(dir != dirActual){
    esperando++;
  } else{
    autosEnVia++;
    barraDePaso[dir].release();
  }
  mutex.release();

  barraDePaso[dir].acquire();

  // tiempo de pasar el puente

  mutex.acquire();
  autosEnVia--;
  if(autosEnVia == 0){
    dirActual = 1 - dir;
    barraDePaso[1-dir].release[esperando];
    esperando = 0;
  }

  mutex.release();
```

## Punto b

Globales:
```
int autosEnVia = 0;
int dirActual = 0;
int[] esperando = {0,0};

Semaphore mutex = new Semaphore(1,true);
Semaphore[] barraDePaso = {new Semaphore(0,true), new Semaphore(0,true)};
```

Auto:
```
Thread auto(int dir):

  mutex.acquire();
  if(autosEnVia == 0 && dir != dirActual){
    dirActual = dir;
    autosEnVia++;
    barraDePaso[dir].release();
  } else{
    esperando[dir]++;
  }
  mutex.release();

  barraDePaso[dir].acquire();

  // tiempo de pasar el puente

  mutex.acquire();
  autosEnVia--;

  if(autosEnVia < 3){
    // Si no hay nadie esperando del otro lado sigo con la misma dirección
    if(esperando[dir] >= 0 && esperando[1-dir] == 0){
      autosEnVia += min(esperando[dir], (3-autosEnVia));
      barraDePaso[dir].release[min(esperando[dir], (3-autosEnVia))];
    }
    // Si soy el último en pasar por la via y hay alguien esperando del otro lado, cambio mi dirección
    if(autosEnVia == 0 && esperando[1-dir] > 0){
      dirActual = 1 - dir;
      autosEnVia += min(esperando[1-dir], 3);
      barraDePaso[1-dir].release[min(esperando[1-dir], 3)];
    }
  }

  mutex.release();
```

## Punto c

Si hay alguien esperando del otro lado se impide que siga pasando gente y se libera del otro lado, pero para esto al menos uno de cada lado pasó.
