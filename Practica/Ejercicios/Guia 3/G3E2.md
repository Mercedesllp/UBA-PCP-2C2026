# Ejercicio 2 - Guia 3

Un secuenciador ternario proporciona tres operaciones: primero(), segundo(), y
tercero(). Se desea implementar un monitor SecuenciadorTernario para coordinar a threads que pueden invocar a cualquiera de las operaciones. El secuenciador debe alternar cíclicamente la ejecución de primero, luego segundo, seguido de tercero, para luego repetir la secuencia desde primero. Escriba el código para secuenciadorTernario.


## Solucion

Asumo que se trabaja siempre en Mesa ya que es lo que se usa actualmente.

``` java
monitor secuenciadorTernario {

  volatile int turno = 1;

  condition pri();
  condition seg();
  condition ter();

  public void primero(){
    while(turno != 1){
      ter.wait();
    }
    // codigo
    turno = 2;
    pri.signal()
  }
  public void segundo(){
    while(turno != 2){
      pri.wait();
    } 
    // codigo
    turno = 3;
    seg.signal();
  }
  public void tercero(){
    while(turno != 2){
      ter.wait();
    } 
    // codigo
    turno = 1;
    ter.signal();
  }
}
```
