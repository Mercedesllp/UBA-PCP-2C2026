# Ejercicio 1 - Guia 3

## Punto a
Signal y espera es política de Hoare:

``` java
T1:
  // antes
  permiso.signal() -> no tiene efecto pq no hay ninguno bloqueado
  // despues
T2: 
  permiso.wait() -> deadlock
```



## Punto b
Signal y continúa es Mesa:

``` java
T1:
  // antes
T2:
  permiso.wait()
T1:
  permiso.signal()
  // despues
T2:
  // importante
```

No es el orden correcto. Hay varias formas de que sea un caso exitoso. Como es signal y continúa siempre sigue T1 desp del signal.
